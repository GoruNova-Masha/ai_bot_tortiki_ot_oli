# Настройка Google Таблицы для заявок бота «Тортики от Оли»

## Быстрый старт

1. Скачайте JSON-ключ сервисного аккаунта Google (см. ниже).
2. Положите файл в `credentials/google-service-account.json`.
3. (Опционально) Укажите в `.env` email Оли/менеджера:
   ```env
   GOOGLE_SHEETS_SHARE_EMAIL=email@gmail.com
   ```
4. Запустите **`setup_google_sheets.bat`** — скрипт создаст таблицу, шапку, тестовую строку и пропишет ID в `.env`.
5. Перезапустите **`run.bat`**.

---

Интеграция записывает каждую заявку в Google Таблицу через **Service Account** и библиотеку **gspread**.

## 1. Google Cloud — сервисный аккаунт

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).
2. Создайте проект (или выберите существующий).
3. Включите API:
   - **Google Sheets API**
   - **Google Drive API**
4. **IAM & Admin → Service Accounts → Create service account**
   - Имя, например: `tortiki-bot-sheets`
   - Роль можно не назначать (доступ к таблице дадим вручную)
5. Откройте созданный аккаунт → **Keys → Add key → JSON**
6. Сохраните файл в проект:
   ```
   credentials/google-service-account.json
   ```
   ⚠️ Не коммитьте этот файл в git.

## 2. Google Таблица

1. Создайте таблицу с именем **Заявки_ТортикиОтОли** (или любым — тогда укажите имя в `.env`).
2. Скопируйте **ID таблицы** из URL:
   ```
   https://docs.google.com/spreadsheets/d/ВАШ_ID/edit
   ```
3. Откройте **Настройки доступа → Добавить пользователей**
4. Вставьте email сервисного аккаунта из JSON (`client_email`), роль **Редактор**.

При первой записи бот создаст шапку (если первый лист пустой):

| ID заявки | Дата создания заявки | Тип торта | Вес (кг) | Вкусы начинки | Дата доставки | Время доставки | Адрес доставки | Имя клиента | Телефон клиента | Статус |
|-----------|----------------------|-----------|----------|---------------|---------------|----------------|----------------|-------------|-----------------|--------|

Статус при записи: **В работе**.

## 3. Переменные в `.env`

```env
GOOGLE_SHEETS_CREDENTIALS_PATH=credentials/google-service-account.json
GOOGLE_SHEETS_SPREADSHEET_ID=ваш_id_из_url
GOOGLE_SHEETS_SPREADSHEET_NAME=Заявки_ТортикиОтОли
GOOGLE_SHEETS_WORKSHEET_NAME=Лист1
GOOGLE_SHEETS_RETRY_MINUTES=5
```

Достаточно указать **либо** `GOOGLE_SHEETS_SPREADSHEET_ID`, **либо** `GOOGLE_SHEETS_SPREADSHEET_NAME`.

Если ключ или ID не заданы — бот продолжит работать: номер заявки выдаётся локально, в Telegram уходит уведомление менеджеру.

## 4. Установка зависимостей

```bat
install_deps.bat
```

или:

```bat
.venv\Scripts\pip install gspread google-auth
```

## 5. Проверка

1. Запустите `run.bat`.
2. В консоли должно быть: `Google Sheets: включена, повтор буфера каждые 5 мин`.
3. Оформите тестовую заявку через `/order`.
4. Клиент получит: **«Заявка №N принята…»**
5. В таблице появится новая строка.

### Логи

- Успех: `Заявка №N записана в Google Таблицу`
- Сбой API: `Заявка №N не записана — добавлена в буфер`
- Повтор: `Заявка №N из буфера записана в Google Таблицу`

Буфер хранится в `data/sheets_buffer.json`. Повтор каждые 5 минут (настраивается).

## 6. Откуда берутся поля таблицы

| Столбец | Источник в боте |
|---------|-----------------|
| ID заявки | Автонумерация (`data/lead_id_counter.json`) |
| Дата создания | Дата оформления заявки |
| Тип торта | Ответ «Что тебя интересует?» |
| Вес, вкусы, дата/время доставки | Парсятся из текста ТЗ (кг, «15 мая», «в 18:00» и т.п.) |
| Адрес доставки | Город клиента или строка «адрес: …» из ТЗ |
| Имя, телефон | Шаги заявки |
| Статус | «В работе» |

Полное ТЗ по-прежнему приходит менеджеру в Telegram.
